Cấu hình Token cho Team

Yêu cầu Token: Tạo tại mục API -> Tokens trên DigitalOcean với 2 quyền bắt buộc: account:read và billing:read. Hệ thống sẽ kiểm tra trực tiếp qua API trước khi lưu mã hóa vào DB.
Dạng: dop_v1_... (Bắt buộc thuộc đúng team này).

🏢 Thêm Khách Hàng / Organization từ Token

Dành cho khách hàng dùng Organization riêng và chỉ cấp Personal Access Token (PAT) từ tài khoản Owner của Org. Hệ thống sẽ tự động gọi DO API xác thực và thêm Org vào danh sách quản lý.
Token phải có 2 quyền bắt buộc: billing:read và account:read.
